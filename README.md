# Стратегия на акциях S&P 500

Mid-Frequency стратегия на акциях S&P 500, где CatBoost предсказывает вероятность того, что акция обгонит SPY за следующие 21 торговый день.

## Структура работы

Три последовательных шага:

1. get\_data — скачивание цен через yfinance, фильтрация по актуальным тикерам SPY, генерация фичей и таргета, сохранение parquet файлов
2. train — подбор гиперпараметров через PurgedKFold, оценка обученной модели с помощью Combinatorial Purged Cross Validation
3. run\_backtest — генерация весов портфеля, запуск бэктеста через vectorbt, сохранение метри и графиков

## Запуск

```bash
python main.py          # полный пайплайн (скачивание и получение данных, обучение модели, бэктестирование)
```
```bash
python backtest_only.py # только бэктест (использует сохранённую модель и данные)
```
